# medrec-starter

Boilerplate Sistem Informasi Rekam Medis (SIMRS sederhana) untuk mahasiswa RMIK / Informatika Kesehatan.

## Instalasi

```bash
npx create-medrec-app nama-klinik-saya
cd nama-klinik-saya
npm install
npm start
```

Akses aplikasi di `http://localhost:3000`.
